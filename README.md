This project builds a smart multiple-choice question solver using deep learning and GenAI techniques. The current repository layout separates the notebook work, model artifacts, report output, and the future FastAPI application so the project can grow in a clean, maintainable way.

## Repository structure

- `notebooks/` — the main project notebook for experimentation and development.
- `models/` — trained model artifacts such as weights, vocabulary files, and checkpoints.
- `reports/` — the final project report PDF will be stored here.
- `app/` — the FastAPI application package for deployment and inference.
